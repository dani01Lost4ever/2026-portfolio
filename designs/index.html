Portfolio redesign proposals

Three concepts, each built around one scroll-driven animation that runs through the whole page. Open one and scroll.

Signal
A single request travels one amber route down the page: it draws a glyph for each project, splits into four skill lanes, merges into a git-graph career timeline and ends at the contact box as a 200 OK.
SVG + GSAP ScrollTrigger
The Stack
A pinned 3D stack of four slabs (Interface, API, Queue, Database) reconfigures itself for every section: each project's real architecture, a skill grid, a career staircase, and finally a contact card, over colour-blocked backgrounds.
CSS 3D + GSAP ScrollTrigger
Field
Ten thousand points behind the page morph from a data grid into one shape per project, then skill clusters, a helix timeline and an @ for contact.
three.js point cloud + GSAP ScrollTrigger
