AuroraTrader

An AI paper-trading agent that trains its own replacement

The agent asks Claude for trade decisions, executes them on the Alpaca Paper API and logs every call to MongoDB. Profitable trades export as a JSONL dataset that fine-tunes a local Ollama model, which then drops back into the same loop and replaces the Claude calls.
